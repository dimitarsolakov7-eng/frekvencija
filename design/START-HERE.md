# Frekvencija website design pack

Brand: **Frekvencija**  
Domain: **frekvencija.online**

This pack contains eight website screen designs, the approved logo, a dark-background logo variant, a reusable venue photograph, and a developer handoff.

## Send this to Claude

1. Upload **Frekvencija-Website-Design.pdf** to show the whole visual direction.
2. Give Claude this folder or upload **CLAUDE-HANDOFF.md**, **FUNCTIONAL-BUILD-PROMPT.md**, and the numbered images in **screens/**.
3. Give Claude the **assets/** folder so it can use the actual logo and background image.

If your Claude interface cannot open ZIP files, extract the ZIP first.

Copy this message:

> Build Frekvencija at frekvencija.online using the attached visual designs. Read CLAUDE-HANDOFF.md and FUNCTIONAL-BUILD-PROMPT.md before writing code. Use the supplied PNG logos and venue photograph. Recreate the designs with real responsive components, forms, authentication, and audio playback. I own one shared music catalogue organized into genres. Each business logs in and plays independently from that same catalogue, with its own approved station announcements. I must be able to upload songs and manage genres at any time from the admin dashboard. Start with a short plan, then implement the working project. Follow the handoff's behavior and accessibility notes when a small detail in a mockup differs.
